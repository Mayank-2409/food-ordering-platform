# Architecture Overview

## Architecture Style
**Modular Monolith**

The application is designed as a modular monolith:
- Clear separation of domains
- Feature-based structure
- Easy to evolve into microservices later

---

## High-Level Components

- Frontend (Next.js)
- Backend API (planned)
- Database (planned)
- Cache (planned)
- External services (payments, notifications)

---

## Why Modular Monolith
- Solo developer friendly
- Faster iteration
- Easier debugging
- Avoids premature complexity

---

## Future Evolution
- Introduce backend API
- Add caching and async processing
- Extract services if scale requires it
